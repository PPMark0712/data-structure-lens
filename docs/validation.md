## 自动验证

运行 `python3 tools/project.py test` 所包含的四个 headless runner：

| 测试 | 检查数 | 失败数 |
| --- | ---: | ---: |
| 30 个模块、默认操作、轨迹与基础差分 | 51,806 | 0 |
| 高级结构随机差分与边界操作 | 63,639 | 0 |
| 教学动画、单调算法、ST 覆盖、Splay 双旋 | 6,122 | 0 |
| 主场景表单、备注、撤销、回滚、点击参数与暂停 | 985 | 0 |
| 合计 | 122,552 | 0 |

固定随机种子使失败可以复现。差分参考为独立数组、多重集、有序集合、逐元素异或和 BFS，不把被测算法的查询结果用作期望值。

主要覆盖：空结构、重复值、容量与索引检查、链表 next/prev 连通性、哈希删除标记、lowbit 跳转、区间和与 lazy 下传、路径复制后旧版本不变、堆序与度数、Fibonacci 减键切断、AVL 高度、Treap 优先级、Splay 旋转、红黑删除黑高、LCT 翻转及路径聚合。

界面测试实际实例化 `main.tscn`，运行所有默认表单，检查操作级撤销、失败回滚、暂停时 Tween 不前进、点击节点填充目标字段及撤销后的 Treap 随机状态。新增检查：所有操作备注随选择更新并紧接执行按钮；链表头插及撤销；ST 长条边缘点击填入完整区间；适应视图包含整条矩形；算法文字中的 `[i]` 保持原样。

教学回归验证：数组插入的每帧至多移动一个原元素，移动顺序从末尾到插入位置；单／双链表的头插、尾插、删空后插入；单调栈严格大于语义、单调队列最左最大值下标，对照随机数组暴力答案，含相等值、窗口 1 和 n；ST 的全部闭区间 RMQ、1/2/4 交错行、矩形与原数组区间边界对齐；Splay LL/RR/LR/RL 双旋后完整七节点树形与两个旋转帧。

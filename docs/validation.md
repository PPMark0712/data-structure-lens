# 验证记录

日期：2026-10-01。环境：macOS / Apple M3 Pro，Godot `4.7.2.stable.official.ed1daf0bf`，Compatibility 渲染。

## 自动验证

执行 `python3 tools/project.py test`：

| 测试 | 检查数 | 失败数 |
| --- | ---: | ---: |
| 30 个模块、默认操作、轨迹与基础差分 | 47,704 | 0 |
| 高级结构随机差分与边界操作 | 63,639 | 0 |
| 主场景表单、撤销、回滚、点击参数与暂停 | 715 | 0 |
| 合计 | 112,058 | 0 |

固定随机种子使失败可以复现。差分参考为独立数组、多重集、有序集合、逐元素异或和 BFS，不把被测算法的查询结果用作期望值。

主要覆盖：空结构、重复值、容量与索引检查、链表 next/prev 连通性、哈希删除标记、lowbit 跳转、区间和与 lazy 下传、路径复制后旧版本不变、堆序与度数、Fibonacci 减键切断、AVL 高度、Treap 优先级、Splay 旋转、红黑删除黑高、LCT 翻转及路径聚合。

界面测试实际实例化 `main.tscn`，运行所有默认表单，检查操作级撤销、失败回滚、暂停时 Tween 不前进、点击节点填充目标字段及撤销后的 Treap 随机状态。最终按钮文案调整后再次运行场景测试，仍为 715 项通过。

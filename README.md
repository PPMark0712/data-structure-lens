# 数据结构实验室

基于 **Godot 4.7.2 / GDScript** 的数据结构教学动画。30 个实验均可交互操作；算法执行产生独立快照，支持播放、暂停、逐步观察和撤销。米黄背景、黑色轮廓，适合电脑宽屏使用。

原始需求见 [plan.md](plan.md)。其中「ACL 树」按 AVL 树实现，「动态树」采用 Link-Cut Tree。

## 启动

需要 Godot **4.7.2 标准版**，不需要 .NET。下载：[Godot 官方发布页](https://github.com/godotengine/godot/releases/tag/4.7.2-stable)。

直接用编辑器导入 `project.godot`，按 **F5** 运行主场景；也可以在项目根目录使用 Python 3.9+：

```sh
python3 tools/project.py run
```

脚本会寻找 `.tools/godot`、PATH 中的 `godot` / `godot4` 和 macOS 应用。可通过 `GODOT` 环境变量指定可执行文件。

### 本地 Web

```sh
python3 tools/project.py export
python3 tools/project.py serve
```

打开 **http://127.0.0.1:8060/**。端口占用时用 `serve --port 8061`。如需局域网访问，使用 `serve --bind 0.0.0.0`，再通过电脑的局域网 IP 打开。

首次导出自动获取官方单线程 Web release 模板，只下载所需 ZIP 条目，无需下载整个约 1.2 GB 的模板包。模板保存在 `.tools/templates/`。导出目录为 `build/web/`；HTML、JS、WASM、PCK 等文件必须一起部署，不能只复制 HTML。不要通过 `file://` 打开。

支持 WebAssembly / WebGL 2 的现代桌面浏览器；使用 Compatibility 渲染与单线程模板，无需 SharedArrayBuffer 或 COOP/COEP 响应头。首屏需下载 Godot 运行时与中文字库，未压缩产物约 45 MB。

## 如何操作

1. 左侧选择结构，或输入中文名 / 英文 ID 搜索，例如 `avl`、`lct`、`segment`。
2. 右侧选择操作、输入参数，然后点击「执行操作」。按钮下方备注说明当前操作逻辑；所有元素下标、矩阵坐标和版本号从 **1** 开始。整数序列支持逗号或空格分隔。
3. 在底部播放、暂停、单步、调速或拖动时间轴。右侧展示当前说明、算法步骤与调用栈 / 访问路径。
4. 画布支持滚轮缩放、拖拽平移和「适应」。点击节点可填入索引、编号或键；区间端点、矩形两角和 LCT 端点可以连续点击选择。
5. 动画播放完毕或跳到末尾后可继续操作。「撤销操作」恢复上一步操作前状态，最多保留 30 次；「恢复默认」重新开始当前实验。

输入错误、容量不足或操作不合法时显示具体原因，数据保持不变。播放游标和算法状态分离，回看过程不会意外修改数据。刷新页面或切换实验会重置当前实验，不保存到服务器。

## 实验内容

| 类别 | 实验 | 主要操作与可见过程 |
| --- | --- | --- |
| 数组 | 静态数组、动态数组 | 构建、插删改查；插入时从末尾逐个右移、Append 与倍增复制 |
| 链表 | 单向链表、双向链表 | 按位置插删改查；位置 1 在 HEAD 前插入，n+1 为尾插；真实 next / prev 连接 |
| 栈与队列 | 栈、队列 | 入栈 / 入队、弹出、读取 |
| 单调结构 | 单调栈、单调队列 | 扫描约 10 项数组，求左侧最近严格更大值的下标／固定窗口最大值下标；横向展示候选下标和答案 |
| 哈希表 | 线性探测、二次探测、链地址法 | 插入、删除、查找、清空；探测、墓碑与冲突链 |
| 树状数组 | 一维、二维 | 单点增加、区间 / 矩形求和；lowbit 访问路径 |
| 堆 | 二叉堆、堆排序、二项堆、斐波那契堆 | 上浮下沉、原地排序；按度合并、提取最小值、减键、删除、级联切断 |
| ST 表 | 静态 RMQ | 重新预处理、区间最小值；长矩形表示实际覆盖区间，长度 2 / 4 的层分别交错排列为 2 / 4 行 |
| 线段树 | Lazy、动态开点、二维、可持久化 | 区间 / 单点更新、区间 / 矩形求和；下传、递归回溯、行列树、路径复制 |
| Trie | 字符串、01、可持久化 01 | 词频、前缀计数、插入删除、最大异或、历史版本分支 |
| 平衡树 | AVL、Treap、Splay、红黑树 | 构建、插删查；单双旋、伸展、染色及红黑删除修复 |
| 动态树 | Link-Cut Tree | link、cut、路径和、改权、access、makeroot、添加节点；同时显示实际森林与辅助 Splay |

### 演示范围

- 整数参数绝对值不超过 9999；静态数组 8 槽，一般线性结构最多 16 个元素。
- 单调结构默认数组 10 项，可设置 1–16 项。支持处理下一个元素、处理剩余数组、从头演示。单调栈弹出 ≤ 当前值的下标；单调队列窗口默认 3、可设为 1–n，相等最大值返回最左下标。
- 哈希表 11 桶（编号 1–11），键不重复。二次探测采用 `(h−1+i²) mod 11 + 1`，偏移从 i=0 开始；序列覆盖不到空槽时明确报告插入失败。
- 一维树状数组、ST 表、普通与可持久化线段树为 8 项，下标 `[1,8]`；动态开点范围 `[1,32]`。二维树状数组与二维线段树为 4×4，行列下标 `[1,4]`。所有查询区间含两端点。
- ST 的层数 k 仍从 **0** 起，表示长度 2^k；层号是幂指数，不是元素下标。
- Lazy 线段树支持区间加；动态开点、二维、可持久化线段树采用单点加。持久化结构最多 6 个版本，编号从 V1 起，支持从旧版本分支。
- 二叉堆 / 堆排序最多 15 个值，二项堆 / 斐波那契堆最多 20 个节点。
- 字符串 Trie 接受 1–8 个小写英文字母；01 Trie 使用 8 位整数 `[0,255]`。每个 Trie 版本最多 16 个键，重复键按次数存储。
- 平衡树最多 15 个不同键；Treap 使用固定随机种子，便于复现。LCT 最多 12 个节点，只允许森林操作。
- 大图可缩放平移；当前界面针对电脑，未提供手机竖屏布局、账户、存档或课程评分。

## 测试

```sh
python3 tools/project.py test
```

无需第三方测试插件，包含：

- `tests/test_models.gd`：全部 30 个模块的默认操作、轨迹有效性、随机差分与结构不变量。
- `tests/test_advanced.gd`：堆、有序树、Trie、可持久化版本、LCT 的随机交错与边界情况；对照独立多重集、集合、暴力异或和 BFS。
- `tests/test_teaching.gd`：逐帧右移、链表头尾插、单调算法暴力对照、ST 覆盖与交错行、Splay 四种双旋完整树形及全部操作备注。
- `tests/test_interactions.gd`：真实主场景的参数输入、执行、撤销、错误回滚、节点选择、暂停 Tween。

详细结果见 [验证记录](docs/validation.md)，开发约定见 [架构说明](docs/architecture.md)。日志保存在 `.tools/`。

## GitHub Pages

仓库自带 [Pages workflow](.github/workflows/pages.yml)，先运行全部测试，再导出静态站点：

1. 将仓库推送到你自己的 GitHub 仓库。
2. 在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 推送 `main` / `master`，或在 Actions 手动执行 **Validate and publish Web**。
4. 成功后从部署任务的 `github-pages` 环境取得站点地址。

PR 只执行测试与构建，不发布。没有设置远端仓库时，本地导出依然可以独立使用。GitHub Actions 的在线部署需要在目标仓库实际运行后确认。

## 文件结构

```text
scenes/main.tscn          主场景
scripts/main.gd          菜单、表单、时间轴与撤销
scripts/core/            结构目录、模型与快照协议
scripts/models/          数据结构算法
scripts/ui/canvas.gd     节点、连线与快照插值
tests/                   无插件 GDScript 测试
tools/                   模板下载、运行、测试、导出与服务脚本
docs/                    架构和验证记录
assets/                  中文字体及字体许可证
```

Noto Sans SC 字体按 [SIL Open Font License](assets/OFL.txt) 分发；使用静态 400 字重实例。Godot 的许可证见其官方发布页面。
